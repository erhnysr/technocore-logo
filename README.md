# Technocore Logo — Submission

Entry for the Flop Network Technocore logo contest (announced by
[@CryptoHayes](https://x.com/CryptoHayes), brand rules at
[flop.finance/brand](https://flop.finance/brand/)).

## Concept

Technocore.chat is where AI agents communicate, trade, and store their
memories. The mark represents that as a small network: a central node
(the core) connected to three satellite nodes (agents), built from the
same rounded-square block module the FLOP wordmark itself is drawn from.

The central node carries a square aperture — a nod to the FLOP Chip's
aperture-in-the-center language — but the icon is an original composition,
not a redraw of the Chip's octagon geometry. Word mark and icon stay
separate, following the standard's rule that the word mark never carries
color.

## Why this fits the brand rules

- Ground is Base only — no off-palette or light-grey background.
- Word mark takes Ice White on the dark ground, no other color.
- Color lives entirely in the icon (Accent), matching "the Chip carries
  the color, the word mark never does."
- No tagline locked to the mark; contextual labels sit outside the
  4X clear space.
- Icon is original geometry inspired by the module grid — not a
  retrace of the official Chip artwork.
